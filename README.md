# Pharmacy Inventory Analysis

This project is a simple pharmacy inventory tracker built using Python and pandas. It simulates a small-scale pharmacy environment and analyzes which medications are running low and when they may need to be reordered based on weekly sales trends.

## 🔍 Objective

To practice basic data analysis and visualization by:
- Identifying drugs that are low on stock
- Estimating how many days until stock runs out
- Visualizing inventory levels

## 🛠️ Tools Used
- Python
- pandas
- matplotlib

## 📊 Features
- Loads fake pharmacy inventory data
- Flags medications that fall below reorder thresholds
- Calculates estimated days until stock depletion
- Visualizes current stock levels with color-coded bar charts

## 📁 Files
- `inventory_analysis.ipynb`: The main Jupyter Notebook with code and charts
- (Optional) `inventory.csv`: The dataset (if you created one separately)
